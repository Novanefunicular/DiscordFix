> Один и тот же инструмент могут применять как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как инструменты повышенного риска или хакерские средства. В результате файл удаляется и отправляется в карантин. В названии обнаружения обычно присутствует `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы понимаете настройки исключений, предпочтительно добавить исключение. При отсутствии такой уверенности рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика услуг DNS, отличный от "Поставщика по умолчанию"
    * В Firefox выберите "DNS через HTTPS", режим "Персональный", затем пункт "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы - [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется
    * На роутерах Keenetic активируйте параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно

2. Загрузите zip/rar-архив с [последнего релиза](https://github.com/Novanefunicular/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и установите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот пункт можно пропустить

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите подходящий файл
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы включить автоматический запуск, выберите **`service.bat`** -> `Install Service` -> *подходящую стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты (ALT, FAKE и другие), пока не найдёте подходящий именно для вас**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавить выбранную стратегию в автозапуск (services.msc)</ins>
  - **`Remove Services`** - удалить стратегию и WinDivert из служб
  - **`Check Status`** - посмотреть состояние обхода и служб, включая стратегию автозапуска и WinDivert
  - **`Game Filter`** - изменить режим обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения режима стратегию нужно перезапустить.**  
  Текущее состояние (включено/выключено) отображается в скобках.
  - **`IPSet Filter`** - изменить режим обработки сервисов, перечисленных в `ipset-all.txt`.  
  Это может пригодиться при проверке ресурса, который без zapret работает, а с ним - нет.  
  В скобках отображается активный режим:
    - `none` - IP-адреса не проверяются
    - `loaded` - проверяется наличие IP в списке
    - `any` - под фильтр попадает любой IP
  - **`Auto-Update Check`** - включить или отключить автоматическую проверку обновлений
  - **`Replace active fakes`** - заменить используемый фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** - получить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** - вручную проверить наличие обновлений
  - **`Run Diagnostics`** - найти распространённые причины неисправности zapret.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапной остановке работы приложения
  - **`Run Tests`** - открыть проверку стратегий:
    - `Standard tests` - тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` - проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска `general*` ничего не открывается

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход), видимый на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/Novanefunicular/zapret-discord-youtube/issues/522)

### Рабочей стратегии не нашлось
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из появившегося Блокнота
  - В созданной папке найдите `hosts` и откройте его текстовым редактором от имени администратора
  - Вставьте скопированное содержимое в конец `hosts` или замените ранее добавленный аналогичный фрагмент
  - Сохраните файл и снова проверьте соединение. Если результата нет, убедитесь, что изменения действительно записались.

#### Работа функции не гарантируется. Если способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/Novanefunicular/tg-ws-proxy) или любым публичным прокси.

### Обход перестал работать

> [!IMPORTANT]
> **Стратегия, которая работала раньше, со временем может стать неэффективной.**
> Определённая стратегия может действовать некоторое время, а затем перестать работать после обнаружения.
> В репозитории собрано много вариантов обхода. Если ни один не подходит, создайте новую стратегию на основе имеющейся и измените её параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и проверьте, нет ли ошибок

- Проверьте, присутствует ли адрес нужного ресурса в списках доменов или IP

- Переберите другие стратегии, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/Novanefunicular/zapret-discord-youtube/issues/765)

### Как полностью переустановить или обновить проект?
- Сохраните добавленные вами ресурсы и другие данные
- Перезапустите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; если найдены ошибки, исправьте их и в конце выберите Y
- Удалите каталог zapret
- Загрузите актуальную версию [со страницы релизов](https://github.com/Novanefunicular/zapret-discord-youtube/releases), файл вида `zapret-discord-youtube-...`
- Нажмите правой кнопкой по архиву и откройте свойства. Если внизу справа есть флажок разблокировки, установите его, нажмите "Применить" и "ОК"
- Распакуйте архив в новый каталог в корне диска, без пробелов, специальных символов и кириллицы
- Запускайте разные `general`-скрипты и проверяйте доступность ресурсов. Если интернет-ресурсы не открываются, завершите программу через значок замка на панели задач и выберите другую стратегию
- После нахождения подходящей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service`

### Игра или приложение не работает при включённом zapret

- Убедитесь, что в `service.bat` значение `Game Filter` установлено в **`disabled`**, а `IPSet Filter` - в **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. Найдите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал противодействовать таким расширениям.
- Переберите остальные стратегии, особенно если раньше доступ уже работал.
- Дополнительные сведения: [#251](https://github.com/Novanefunicular/zapret-discord-youtube/discussions/251)

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord
- Проверьте, заработало ли приложение после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей
- Если Discord не открывается и в браузере, снова проверьте остальные стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/Novanefunicular/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/Novanefunicular/tg-ws-proxy)
- Другой вариант - применить бесплатные MTProto-прокси из интернета

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Универсальная последовательность действий:
- через `service.bat` обновите ipset и включите `Game Filter`
- если это не помогло, дополнительно включите `ipset any`

Учтите, что режим `ipset any` способен нарушить открытие большого числа сайтов. Не оставляйте его включённым постоянно: определите все IP-адреса игры и добавьте их в `ipset-all.txt`

Если результат всё равно отсутствует, создайте обсуждение в разделе [Discussions](https://github.com/Novanefunicular/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Подходящей проблемы в списке нет

- Создайте обращение [здесь](https://github.com/Novanefunicular/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены-исключения, например когда IP сети есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - исключаемые IP-адреса и подсети
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
